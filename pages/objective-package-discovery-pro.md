Objective Package Discovery Pro is the planned premium extension for the public `ObjectivePackageDiscovery` core.

The goal is to help teams move beyond one-off package lookup and into repeatable dependency-governance workflows.

## Planned Focus

- organization-specific policy packs
- saved presets for package approval standards
- private registry adapters
- review-ready reports and decision exports
- stronger governance modes for AI-agent-assisted dependency decisions

## Why Split It From The Public Core

The public core should stay visible so developers can trust the recommendation model and package risk checks.

The premium layer is intended to add operational leverage for teams rather than hide the basic idea.
